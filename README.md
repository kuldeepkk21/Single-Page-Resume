# Single Page Resume – HTML

This repository contains a **single-page resume built using HTML**.  
The project focuses on clean structure, readability, and the use of **semantic HTML elements** to create a professional resume layout.

---

## 📄 Project Overview

The resume is designed as a single HTML page and includes the following sections:

- **Heading / Profile Title**
- **About Me**
- **Skills**
- **Experience** (displayed using a table)
- **Projects**
- **Education** (displayed using a table)
- **Contact Information**

Semantic HTML elements are used to improve accessibility, SEO, and code clarity.

---

## 🧱 Technologies Used

- **HTML5**
- Semantic HTML elements (`<header>`, `<section>`, `<article>`, `<table>`, `<footer>`)
